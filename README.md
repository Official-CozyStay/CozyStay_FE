# 🌿 청춘여행 (Frontend)

> **AI 기반 기억 보관함을 통한 치매 어르신 케어 플랫폼**  
> 데이터 기반과 감성 기반의 케어를 동시에 실현하는 **로컬 기반 AI 지원 시스템**

## 주요 기능

| 구분             | 기능 설명                                                                   |
| ---------------- | --------------------------------------------------------------------------- |
| 돌봄 기록 관리   | 대화, 활동, 정서 상태를 캘린더 형태로 기록 및 대시보드로 시각화             |
| 기억 아카이빙    | 과거 사진, 음악, 이야기, 방문 장소를 업로드·보관 및 감정 교감 수단으로 활용 |
| 인지 자극 활동   | AI가 아카이빙 및 기록 데이터를 기반으로 ‘오늘의 대화 주제’ 자동 생성        |
| 행동 패턴 분석   | AI가 선호 장소를 학습하여 노인 실종 시 예상 위치 제공 및 보호자 알림 발송   |
| 통합 계정 시스템 | 환자별 정보 통합 관리, 권한 기반 접근 제어, 실시간 협업형 돌봄              |

## 서비스 특징

### 1. 통합 돌봄 플랫폼

- 보호사·가족·기관이 동일한 시스템 안에서 환자 상태와 기록을 공유
- 분산된 데이터 없이 협력적 돌봄 실현

### 2. 데이터 기반 시각화

- 단순 기록이 아닌 **대시보드형 케어 리포트** 제공
- 대화 빈도, 활동 내역, 정서 상태 추세 등 시각적 분석으로 상태 변화를 한눈에 확인

### 3. AI 기억 추천 시스템

- AI가 개인의 추억 데이터를 기반으로 대화 주제 및 회상 활동 자동 추천
- 보호사 경험 의존도를 낮추고, 어르신에게 지속적 인지 자극 제공

### 4. 행동 패턴 분석 기반 안전 관리

- 어르신의 대화 데이터를 기반으로 이동 패턴 학습
- 예상 위치 예측 및 실시간 알림으로 신속한 대응 지원

## 개발 환경

| 항목                 | 내용              |
| -------------------- | ----------------- |
| **Framework**        | React 18 + Vite   |
| **Language**         | TypeScript        |
| **State Management** | Zustand / Recoil  |
| **Styling**          | styled-components |
| **Routing**          | React Router v6   |
| **API**              | Axios             |
| **Build Tool**       | Vite              |
| **Package Manager**  | npm               |

## 프로젝트 구조

```bash
frontend/
├── public/                    # 정적 리소스 (favicon, index.html 등)
├── src/
│   ├── api/                   # 서버 통신 (axios 인스턴스, API 함수)
│   ├── assets/                # 이미지, 폰트, 아이콘 등 정적 파일
│   ├── components/            # 공용 컴포넌트 (Button, Modal, Card 등)
│   ├── hooks/                 # 커스텀 훅 (useFetch, useModal 등)
│   ├── layouts/               # 공통 레이아웃 (Header, Footer 등)
│   ├── pages/                 # 라우트 단위 페이지 컴포넌트
│   ├── router/                # 라우팅 설정
│   ├── store/                 # 전역 상태관리 (Zustand / Recoil 등)
│   ├── styles/                # 전역 스타일, 테마
│   ├── utils/                 # 헬퍼 함수 및 상수
│   └── main.tsx               # 진입점
├── .env                       # 환경 변수 파일
├── vite.config.ts
├── tsconfig.json
└── package.json
```

## 실행 방법

```bash
# 1. 패키지 설치
npm install

# 2. 개발 서버 실행
npm run dev

# 3. 빌드
npm run build

# 4. 배포 전 확인
npm run preview

```
